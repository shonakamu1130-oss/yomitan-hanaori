# 🌺 トントン織ろう！読谷山花織（よみたんざんはなおり）クラフトスタジオ

子どもたちがスマホやパソコンのWebブラウザ上で、パズルゲーム感覚で読谷山花織の伝統デザインを作成し、コースターやストラップなどの完成品プレビューを確認してスマホに画像保存できるWebアプリケーションです。

---

## ✨ 主な機能

- ✏️ **マス目パズルエディタ**
  - タップ・ドラッグ操作で糸の色や伝統紋様を置くだけ
  - 8×8 / 12×12 / 16×16 のサイズ選択
  - 左右対称デザインモード（花織らしい綺麗な模様が簡単に作れる）
- 🌸 **読谷山花織の伝統紋様スタンプ**
  - **銭花（ジンバナ）**：富と幸福を願う花
  - **風車（カジマー）**：長寿と健康を祈る風車
  - **竹の節（タキノヒー）**：健やかな成長を願う竹
  - **花糸（ハナイティ）**：可憐なアクセント花
- 🎨 **沖縄伝統の糸色パレット**
  - 琉球朱、琉球藍、福木黄、胡粉白、漆黒、萌黄
- 🎁 **リアルな商品プレビュー & 画像保存**
  - コースター、携帯ストラップ、織物しおり、スマホ壁紙、ランチョンマット
  - 本物の糸の質感やフリンジを合成してスマホにPNG画像として保存
- 🔊 **機織りトントン効果音**
  - 機織り機の音（Web Audio API合成音）で本物の織士気分を体験

## 🚀 GitHub Pages へのデプロイ方法

1. GitHubで新規リポジトリ（例: `yomitan-hanaori-app`）を作成します。
2. 本フォルダのコードをコミットしてPushします：
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/あなたのユーザー名/yomitan-hanaori-app.git
   git push -u origin main
   ```
3. GitHubリポジトリの **Settings > Pages** を開き、Sourceを **GitHub Actions** に設定します。
4. 自動的にビルド・デプロイが完了し、指定されたURL（`https://あなたのユーザー名.github.io/yomitan-hanaori-app/`）でスマホから遊べるようになります！
